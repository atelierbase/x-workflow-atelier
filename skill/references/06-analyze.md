# 06-analyze: 週次分析・改善

このフェーズの目的は、週に1度、運用数値を俯瞰して**伸びパターンを学習・撤退ピボット判断する**こと。

## 実行ペース

- 週次（基本）: 毎週金曜夜 or 土曜朝
- 月次（拡張）: 月初に前月総括
- 四半期（拡張）: 3ヶ月ごとに大きな方針見直し

## 入力

- `storage/stocks/posted.md` の数値ログ
- `storage/analytics/YYYY-MM.md`（前週分があれば）
- X Analytics（手動取得、または api モード時は自動）
- LINE登録数（運用ツール側で確認）

## 出力

週次レポート → `storage/analytics/YYYY-MM.md` に追記。

## KPI 定義

### 一次KPI（毎週見る）

| 指標 | 計算 | ターゲット（初期3ヶ月） |
|---|---|---|
| 投稿数 | posted.md の週間カウント | 15-21本（1日3本×7日） |
| 平均 impressions | 投稿の impressions 合計 / 投稿数 | 500〜3000（フェーズ次第） |
| 平均 likes | likes 合計 / 投稿数 | 5-30 |
| 平均 reply | reply 合計 / 投稿数 | 0.5-3 |
| プロフクリック | 投稿経由のプロフ訪問数（X Analytics） | 投稿数 × 5-20 |
| **LINE登録増加数** | LINE側で取得 | **最重要KPI** |

### 二次KPI（月次で見る）

| 指標 | 計算 | 意味 |
|---|---|---|
| エンゲージメント率 | (likes + RT + reply) / impressions | アルゴリズム好感度 |
| プロフィールCVR | LINE登録 / プロフクリック | プロフ文の効果 |
| 投稿あたり登録寄与 | LINE登録 / 投稿数 | コンテンツの誘導力 |
| テーマ別パフォーマンス | 主軸 / サブ軸1 / サブ軸2 ごとの平均 | 配分の妥当性 |

## ステップ

### Step 1. 数値集計

`storage/stocks/posted.md` を読んで、今週分の投稿の数値を集計：

```python
# 擬似コード
週次データ = {
    "投稿数": 投稿件数,
    "impressions_合計": sum(投稿のimp),
    "impressions_平均": avg,
    "likes_合計": sum,
    "likes_平均": avg,
    ...
    "ベストポスト": 最も伸びた1-3本,
    "ワーストポスト": 全く伸びなかった1-3本
}
```

### Step 2. 伸びたパターンの抽出

ベスト3投稿について、共通点を探る：

- 文字数（短い / 中 / 長）
- 出だしの型（数字 / 観察 / 疑問 / 宣言）
- 数字の有無
- テーマ（主軸 / サブ軸）
- 投稿時刻
- 曜日
- 添付画像の有無

例：
```
今週のベスト3:
1. 火曜夜 / 単発 / 数字スタート / 280文字 / 主軸 / 撤退の話
2. 木曜朝 / 単発 / 観察型 / 150文字 / サブ軸1 / 失敗の話
3. 土曜昼 / スレッド / 数字深掘り / 主軸 / 売上内訳

共通点:
- すべて「具体的な数字」を含む
- すべて「失敗・撤退」を含む
- 投稿時刻はバラバラ → 時刻より中身の質が効いている
```

### Step 3. 伸びなかったパターンの抽出

ワースト3も同じく：
```
今週のワースト3:
1. 月曜朝 / 単発 / 抽象的な思考 / 150文字 / サブ軸2 / 結論なし
2. 水曜夜 / 単発 / 教える系トーン / 280文字 / サブ軸1
3. 金曜昼 / 引用RT / コメント弱め / 主軸

仮説:
- 「抽象的・結論なし」が刺さらない
- 「教える系」がキャラとズレた可能性
- 引用RTは元投稿のクオリティに依存しすぎた
```

### Step 4. LINE誘導効果の計測

- 今週のLINE登録数
- どの投稿がきっかけになったか（アンケート任意欄から推測 or 投稿時刻と相関）
- アンケート結果のセグメント分布

セグメント分布の確認：
```
今週のLINE登録 12人 の内訳:
- 副業中 × 物販志向: 4人
- 副業中 × 新収入源: 3人
- 個人事業 × プロダクト: 3人
- 経営者 × AI活用: 2人

→ 副業層が圧倒的多数。X側で副業層への訴求が効いている。
→ 物販系オファーの整備が次の課題。
```

### Step 5. 撤退・ピボット判断

#### 撤退ラインの考え方

X運用そのものの撤退判断は早めに作っておく。例：

- **6週目までに**: 平均 impressions 500未満 → 設計見直し
- **12週目までに**: フォロワー300未満 → 大幅ピボット
- **3ヶ月目**: LINE登録 累計20人未満 → コンセプト自体の見直し

数字は仮。立ち上げ時に決めて posted.md にメモしておく。

#### ピボット候補

数字が出ない場合のピボット候補：
- キャラ強化（似顔絵リファイン、固定ポスト改修）
- テーマ配分変更（サブ軸を主軸に昇格）
- 投稿時刻の集中化
- スレッド比率を上げる
- 引用RT・絡み比率を上げる
- 別アカウント検討（A/B比較）

### Step 6. 次週の方針

3-5項目に絞った具体的な「来週やること」を出す：

```
来週の方針（YYYY-MM-DD 〜 YYYY-MM-DD）:

1. 「数字スタート × 撤退エピソード」型を週3本作る
2. 教える系トーンの投稿は1本までに制限
3. 物販志向への訴求を1本入れる（サブ軸として）
4. 引用RTは2件まで、コメントを長めにする
5. CTA投稿を1本流す（先週はゼロだった）
```

## 月次・四半期の拡張

### 月次（月初）
- 4週分のトレンドを俯瞰
- フォロワー増加率
- 撤退判断ラインの再設定
- 大きな方針の見直し

### 四半期（3ヶ月ごと）
- アカウント全体の存続判断
- コンセプト再定義
- 別アカウント検討
- 出口戦略の見直し（LINE誘導 → 直接商品誘導など）

## 注意

- 数値の追いすぎは禁物。**1指標が落ちても、全体傾向で判断する**
- 「先週との比較」だけでなく「4週移動平均」も見る（ノイズ排除）
- バズった投稿に引きずられて方針を変えない（外れ値の可能性）
- 「数字が悪い ≠ 即撤退」。3-6週の継続観察が原則
- 撤退判断は感情でなく、事前に決めたラインで
