## ターゲット像

**メインターゲット**: **AIで事業作りしたい中級者**

- Claude Code を少し触ったことがある or 触ろうとしている
- 副業〜個人事業層
- 海外の最新AI情報を日本語でキャッチしたい
- AIを業務・事業に活かしたい

**取り込まない層**:
- AIに全く興味ない層
- 上級開発者で「日本語翻訳は不要」な層（英語直読できる人）

## アカウントの役割（一言で）

**Claude Code / Codex の最新情報を、ひろが実務で実際に使ってみて「使えそう」なものを、どんどん紹介していくアカウント。**

単なる海外ニュースの翻訳機ではなく、「20億円作ってきた実業家が、今 AI を相棒に楽しく作っている。その中で見つけた“使えるもの”を共有する」というスタンス。海外情報を WebSearch → 日本語翻訳 → 自分の実務フィルターを通して「これ、いいですよ」と渡す。

## 提供価値（フォローする理由）

```
1. 海外で先行している Claude Code / Codex の最新情報を、日本語で翻訳
2. ひろが実務で使ってみた結果「使える/使えない」の実践フィルター付き
3. ひろ自身の AI 活用実例（数字とセット）
4. AI実業家としての視点・事業作りのリアル
```

## 出口（LINE）

**LINE 名前（仮）**: ひろの部屋 / Atelier Base ラボ（要検討）

**コンセプト**: X で「公開している翻訳・実例」より一段深い情報を提供する場所

**提供価値**:
- Claude Code / Codex の応用テクニック
- 海外の英語ソース原文＋解説
- ひろが事業で使っているプロンプト・設定の共有
- 個別相談

**動線**:
```
X → プロフ / 固定ポスト / CTA → LINE登録
→ 登録直後アンケート（3-4問）
→ セグメントタグ付け
→ AI活用度合いに応じたステップ配信
→ コンサル / 教材 / コミュニティ
```

**アンケート骨子（叩き台）**:
- Q1. いまの状況（会社員 / 副業中 / 個人事業 / 経営者）
- Q2. AI 活用の状況（未経験 / Claude Code 触ったことある / 業務で使ってる）
- Q3. ご興味（最新情報 / コンサル / 教材 / コミュニティ）
- Q4. ご質問・知りたいこと（自由記述）

## 発信の温度感

| 軸 | 方針 |
|---|---|
| 教える / 見せる | バランス。海外翻訳は「翻訳家」、実例は「実践者」、思考は「実業家」 |
| 距離感 | 親しみやすい。馴れ馴れしさは出さない |
| 専門性 | 中級者向け。専門用語は必ず一文で解説 |
| 透明性 | 数字・実例は具体的に出す |
| Claude Code 露出 | **積極的にOK**（v2 から方針転換） |
| 絵文字 | 控えめ（1投稿に0-1個） |
| 煽り | ゼロ |

## コンテンツ生成の鉄則（再掲・必ず守る）

1. **Claude Code / Codex を中心に発信**（積極的に。v2 の「ハウツー出さない」は撤回）
2. **海外情報を翻訳するときは出典明示**（Anthropic 公式 / Reddit / Hacker News / Indie Hackers など）
3. **数字は気持ちとセットで**
4. **本名「石井」は出さない**
5. **「ミライ塾」の名前は絶対に出さない**
6. **「アトリエの店主」「うちのアトリエでは」など旧キャラ用語は出さない**
7. **専門用語は必ず一文で解説**（中級者ターゲットでも初心者を取りこぼさない）
8. **CTAは月1-2回まで**
