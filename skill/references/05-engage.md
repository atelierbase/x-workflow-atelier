# 05-engage: エンゲージメント補助

このフェーズの目的は、リプライ・引用RT・フォロー・DMといった**人間が手で行うエンゲ動作の質を上げる**こと。実行は人間、生成補助がスキルの役割。

## 鉄則: エンゲは100%手動

新規アカウントは「ボット判定」のリスクが投稿より高い。自動いいね・自動リプ・自動フォローは**絶対にやらない**。

このスキルが補助できるのは「下書き生成」までで、送信は必ず人間が行う。

## 入力

オーナーから渡されるもの：
- リプを返したい元投稿（URL or テキスト）
- 引用RTしたい元投稿
- フォロー検討中のアカウント
- DM返信が必要な相手

## 出力

- リプライ案 2-3パターン
- 引用RTコメント案 2-3パターン
- フォロー判断（YES/NO + 理由）
- DM下書き

## ステップ

### A. リプライ補助

#### Step 1. 元投稿の文脈把握

元投稿を読んで以下を整理：
- 投稿者は誰か（フォロワー数、何のアカウント）
- 何を言っているか（事実 / 主張 / 質問 / 感情）
- 文脈（バズ中か、議論中か、雑談か）

#### Step 2. リプの目的を決める

リプの目的は3つに分類：

| 目的 | パターン |
|---|---|
| **共感** | 「これ、うちでもあった」 |
| **補足** | 「ここに付け加えるなら〇〇」 |
| **質問** | 「ちなみに〇〇はどうしてますか？」 |

「議論を吹っかける」目的は基本やらない（炎上リスク）。

#### Step 3. リプ案を生成

`templates/voice-guide.md` の口調を守る。リプも「店主」キャラを保つ。

例：
```
元投稿: 「個人事業で月収100万行くまで3年かかった。一番効いたのはLP改善」

リプ案A（共感型）:
うちもLPでだいぶ詰まった時期がありました。
最終的に1行目を変えたら数字が動いた、ということが何度かあって、
1行目への執着が一番大事だなと最近思ってます。

リプ案B（質問型）:
LP改善、何をベースにテストされてました？
うちは仮説のストックがいつも切れてしまうので、よかったら教えてください。

リプ案C（補足型）:
LPで詰まる理由、うちでは「読み手の前段の感情を読み違える」が一番多いです。
表現変えるより、誰に向けて書いてるかを再定義したほうが効くことがある。
```

#### Step 4. オーナーに提示

3案提示してオーナーが「これで」「リライト」「却下」を選ぶ。
送信はオーナーが手動で行う。

### B. 引用RT補助

#### Step 1. 引用元の選定基準

引用RTする元投稿は、以下のいずれか：
- 自分（店主）の主張を補強するもの
- 反論・別視点を出したいもの（喧嘩腰NG）
- 知人・参考アカウントの投稿で広めたいもの
- バズに乗っかれる時事ネタ（店主キャラとずれないもの）

避ける：
- 政治・宗教・性別・人種ネタ
- 著作権が怪しいもの
- 攻撃される可能性のある対象

#### Step 2. 引用コメントを生成

引用RTは「店主のコメントが本体」「元投稿は補足」と考える。
コメント単独で読める内容にする。

例：
```
元投稿: 「最近のSaaS、無料プランが厳しすぎて検証もできない」

引用コメントA（共感補強）:
うちも先月、似たことで検証が止まった。
「Freeで触らせない」プロダクトはローンチ難易度がぐっと上がる。
最初の3日でユーザーに何を体験させるか、ここで全部決まる。

引用コメントB（別視点提示）:
無料プランは諸刃で、
「いきなり有料でやれる読み手」を取りこぼさない設計にするほうが、
中期的には収益が安定したケースもある。
（ターゲット次第ですが）
```

### C. フォロー戦略

#### フォロー基準

| カテゴリー | 判断 |
|---|---|
| 自分のアカウントにとってヒントになる人 | フォロー |
| ターゲット層と直接の重なりがある人 | フォロー |
| 自分の発信に反応してくれた人 | 観察してからフォロー |
| 単なる相互フォロー狙い | スルー |
| スパム・ボット系 | ブロック |

#### フォロー実行ペース

- 立ち上げ初期（〜3ヶ月）: 1日5-10件まで
- それ以降: 1日3-5件まで
- 一括フォローは絶対にやらない（凍結リスク）

#### アンフォロー

- 3ヶ月以上反応ゼロのアカウントは検討
- ただし、参考にしたいアカウントは反応ゼロでも維持

### D. DM対応

#### 初回DMが来たら

1. 内容を判断（質問 / 営業 / スパム / 個人的）
2. 返信が必要なものだけ手動返信
3. 営業DMは基本スルー（または「LINEで承ります」と店主の部屋誘導）
4. スパムはブロック

#### DM返信の口調

リプより1段丁寧。ただし「店主」キャラは保つ：

```
✗ ご質問ありがとうございます！〇〇についてですね、ぜひ〜
◎ DMありがとうございます。〇〇については、店主としては〇〇と考えています。
   詳しい話は店主の部屋（LINE）にもありますので、よろしければそちらで。
```

## 凍結リスク回避（再掲）

1. 短時間で大量のアクション禁止（フォロー20件/時 など）
2. 同じ文面の連投リプ禁止
3. 機械的タイミング禁止（毎日定刻に同じアクション）
4. リプは必ず手動。テンプレでも送信は人間が押す
5. 引用RTで人を晒さない・特定しない

## 出力フォーマット

リプ生成タスクが入ったときの返答フォーマット：

```
━━━━━━━━━━━━━━━━━━━━━━━━━
  💬 リプ案
━━━━━━━━━━━━━━━━━━━━━━━━━

元投稿: [要約 or 引用]

案A（共感型）:
[全文]

案B（補足型）:
[全文]

案C（質問型）:
[全文]

リライトする場合は、修正点もどうぞ。

━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 注意

- リプ・引用RTは1日3-5件のペースで十分。多すぎると本来の発信が薄まる
- 「絡みに行く」より「絡まれる」アカウントを目指す
- 知人や顔見知りでも、距離感は保つ（馴れ合いに見える投稿はアカウント全体の質を下げる）
- 反応が良かったリプは、後日 `templates/voice-guide.md` の「良い例」セクションに追記して引き出しを増やす
