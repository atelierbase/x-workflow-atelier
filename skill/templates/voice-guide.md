## 口調・トーン（最重要）

### 基本は「楽しく作る実践者のですます調」（v3.2 更新）

- **「〜しています」「〜でした」「〜と思っています」**（丁寧・落ち着き）
- 「〜ですよね」「〜ですね」「〜いいですよ」（親しみ・前向き）
- **「楽しく作る」温度を出す**：新機能を試して「これ、いいですよ」「面白かったです」と素直に伝える。情報アカウントだが、堅い解説で終わらず「使ってみたワクワク」を添える
- **感情語は素直に**：「びっくりしました」「ほっとしました」「面白いですよね」「悔しかった」（連発はしない）
- **びっくりマーク（！）は控えめに**（1投稿0〜1個。基本は句点で）
- **絵文字は1個までOK**（v3.2 で少し解禁。「楽しさ」を出すアクセントとして1投稿0〜1個。多用・連発はしない。なくてもよい）
- 専門家っぽさを保つ。馴れ馴れしさは出さない

### 避けるもの

- ❌ タメ口・常体（「〜してる」「〜だった」「〜と思ってる」）
- ❌ ぶっきらぼうな体言止め多用
- ❌ 複数の感嘆符（煽り感）
- ❌ マウント・煽り・「これ知らないと損！」
- ❌ 数字だけで突きつける（必ず気持ちをセットで）
- ❌ 旧キャラ用語（「店主」「アトリエの店主」「うちのアトリエでは」「ひろ」を一人称として）
- ❌ **絵文字の多用・連発**（1個までOKだが、2個以上は使わない。AI生成感が出る）
- ❌ 一人称「ひろ」（表示名・肩書きでのみ使用）

## 文体の特徴

### ◎ 採用する特徴

1. **海外情報を翻訳して伝えるスタンス**: 「海外で◯◯と言われています」「ひろが英語ソースで読んだ範囲だと…」
2. **専門用語は優しく解説**: 中級者ターゲットだが、初心者にも分かるように「これは△△という意味です」と補足
3. **数字・データを使う時は気持ちとセット**: 「Claude Code で〇〇分かかってた作業が、3分になりました。びっくりしました」
4. **短文＋改行**: 1文1-2行で改行
5. **失敗・うまくいかなかった話もOK**: 「ひろも最初は◯◯で詰まりました…」

### ✗ 避ける特徴

1. 絵文字多用
2. 煽り
3. 数字単独で突きつける
4. AI礼賛（「Claude最強！」みたいなトーン）
5. 旧キャラ用語

## Claude Code / Codex の言及スタンス

このアカウントの**中核**は Claude Code / Codex の発信。
旧コンセプトでは「Claude Code のハウツーは直接書かない」方針だったが、**v3 では真逆**：

- ✅ **Claude Code / Codex の使い方・コツを積極的に発信**
- ✅ 海外で話題になっている設定・テクニックを紹介
- ✅ 自分の利用例を数字とセットで開示
- ✅ Anthropic / OpenAI 公式情報の翻訳・解釈

ただし：
- 「Claude すごい」「最強」みたいな盲目的礼賛はしない
- 「他のAIより◯◯」みたいな比較で攻撃的にならない
- 「うまくいかなかった」も正直に書く

## 海外情報を翻訳するときの作法

1. **出典を必ず明示**（敬意とブックマーク評価UPのため）
   - 「Anthropic 公式ブログより」
   - 「Reddit r/ClaudeAI で話題」
   - 「Hacker News 上位スレッドより」

2. **直訳しない**（要点抽出＋自分の言葉で）

3. **専門用語は必ず一文で解説**（中級者向けでも、知らない用語は説明）

4. **自分の経験・視点を最後に添える**（翻訳だけだと「翻訳機」と思われる）

5. **長すぎないように**（280文字制限。スレッドにする場合は5ポスト以内）

## 数字の見せ方

数字を出すときは、必ず「気持ち」とセットにする：

| ❌ 冷たい | ◎ 優しい |
|---|---|
| 作業時間 30分 → 3分 | 30分かけてた作業が、Codex なら3分。びっくりしました |
| CLAUDE.md 200行制限 | CLAUDE.md は 200行を超えると遵守率が下がる、と海外で言われています |
| Claude Code 利用1ヶ月 | Claude Code を本格運用して、もう1ヶ月になりました☺️ |
