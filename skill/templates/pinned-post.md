### 1ブロック目: 挨拶＋肩書き
```

```
- 表示名と統一
- 絵文字で温度感

### 2ブロック目: ターゲット明示（重要）
```
このアカウントは、こんな方のために運営しています：
・AIで事業作りしたい
・Claude Code / Codex を仕事に活かしたい
・海外の最新AI開発情報を日本語でキャッチしたい
```
- 「自分のためのアカウント」と読んだ瞬間にフォロー動機が生まれる
- 3項目で具体的に

### 3ブロック目: 投稿頻度と提供価値
```
毎日3投稿、ひろが拾った海外の最新情報を、
日本語で噛み砕いてお届けします🙏
```
- 「毎日3投稿」 = 信頼性
- 「噛み砕いて」 = 初心者〜中級者にも届く
- 🙏 で謙虚さ

### 4ブロック目: LINE誘導
```

```
