## なぜ Threads は別ルールなのか

2026年現在の調査で判明した X と Threads の本質的な違い：

| 観点 | X | Threads |
|---|---|---|
| 場の性質 | 公共広場（議論・速報） | **カフェ（共感・会話）** |
| 評価軸 | リアルタイム性・話題性 | **関係性の強さ・会話の深さ** |
| 伸びる投稿 | シャープ・情報密度・トレンド | **会話的・人柄・共感・ストーリー** |
| 収益化 | クリック・インプレッション | **DM・温かいリード・信頼関係** |
| エンゲージ率 | 標準 | X より +73.6%（同内容で2-3倍も） |

→ **「同じネタを Threads 特性に振り直す」**ことで、両方で勝てる設計。

## Threads 専用の口調・トーンルール

### ① 絵文字: OK（控えめに）

X 用 v3.1 では禁止だったが、**Threads では使う**。
ただし連発はしない。1投稿に **1〜2個**まで。

優先絵文字：
- ☺️（柔らかさ・共感）
- 🙏（謙虚さ・感謝）
- ✨（気づき・発見）
- 💭（思考・想い）
- 📚（学び）

避ける絵文字：
- 🔥 🚀 💪（煽り・テンション過剰）
- ハート系 ❤️ 💕（馴れ馴れしい）

### ② びっくりマーク: 少し多めOK

X 用は0-1個だったが、Threads は **2-3個までOK**。
温度感を上げるための道具。

### ③ 締め方: 必ず「問いかけ」か「共感誘発」

**Threads の最大のコツ**：単なる情報伝達で終わらない。

| ❌ X 的な締め | ◎ Threads 的な締め |
|---|---|
| 「シンプルが大事ですね。」 | 「シンプルが大事ですね。皆さんはどうしていますか？」 |
| 「次の弾はもう設計しています。」 | 「次の弾、もう設計しています。皆さんは最近、何に挑戦されていますか？」 |
| 「びっくりしました。」 | 「びっくりしました。同じ経験ある方、いらっしゃいますか？」 |

**問いかけパターン**：
- 「皆さんはどうですか？」
- 「同じような経験、ありますか？」
- 「もしよかったら聞かせてください」
- 「皆さんの工夫も知りたいです」

### ④ 「私の体験」を必ず前面に

Threads は「翻訳家・情報提供者」より「**一緒に走ってる仲間**」が刺さる。

| ❌ 情報メイン | ◎ 体験＋情報 |
|---|---|
| 「海外で◯◯と言われています」 | 「私も先週試してみて、◯◯と感じました」 |
| 「Anthropic が発表しました」 | 「Anthropic の発表、面白くて読み込みました」 |

### ⑤ 短文＋改行を多めに

スマホで読まれるので、**1文1〜2行で改行**。空行も使う。
500字フル活用しつつ、読みやすさを最優先。

### ⑥ 感情語を多めに

- 「びっくりしました」「ちょっと感動しました」「胸が高鳴りました」
- 「悔しかったです」「ほっとしました」「ありがたいです」
- 「いい意味で裏切られました」「思わずメモしました」

## 文体構造の型（Threads 専用）

### 型A: 翻訳＋体験＋問いかけ（標準）

```
[フック：海外で話題の○○]

[ざっくり翻訳：何の話か、専門用語の解説]

[私の体験：試してみた・感じた]

[問いかけ：皆さんはどうですか？]
```

例：
```
海外で話題だった Claude Code Tips、面白くて翻訳してみました。

「CLAUDE.md は 200行以下に。
 それを超えると、Claude の指示遵守率が下がる」

私も最近、書きすぎてしまって動作が不安定になった経験があります☺️
シンプルさが大事ですね。

皆さんも、CLAUDE.md でハマったこと、ありませんか？
```

### 型B: 自分の実例＋気づき＋共感誘発

```
[シーン描写：今日、こんなことがありました]

[具体的な数字・行動]

[気づき・感情]

[共感誘発：同じような方いますか？]
```

例：
```
今朝、Codex に「このCSV整形して」って頼んだら、
3分で終わりました。

これまで半日かけて Excel と格闘してたんですよね…
ちょっと感動しちゃいました✨

AI で浮いた時間、何に使ってますか？
私は新サービスの設計に再投資するようにしています🙏
```

### 型C: 観察＋哲学＋対話招待

```
[最近気づいたこと]

[なぜそう思うか・背景]

[読み手への投げかけ]
```

例：
```
最近、強く思うことがあります。

AI を「使い倒す」より「相棒として迎える」方が、
長く続く運用になるんじゃないかと💭

「任せきり」だと責任が曖昧になるし、
「使い倒す」だと自分が消耗する。

皆さんは、AI とどんな距離感で付き合っていますか？
```

## 数字の見せ方

X と同じく、必ず「気持ち」とセット。Threads ではさらに感情を一段上げる：

| ❌ 冷たい | ◎ Threads 向け |
|---|---|
| 30分→3分 | 30分かかってた作業が3分に。ちょっと感動しちゃいました✨ |
| 200行制限 | 200行を超えると指示遵守率が下がる、と聞いてびっくりしました |

## NG 例（Threads では特に避ける）

```

Anthropic が CLAUDE.md は 200行以下推奨と発表しました。
シンプルにしましょう。
→ Threads では「で？」「だから何？」になる。問いかけと体験が必要。

[NG例 2: マウント口調]
CLAUDE.md を 200行超えて書いてる人、まだいるんですか？
→ Threads の「supportive culture」と相性最悪。

[NG例 3: X 用そのまま]

```
