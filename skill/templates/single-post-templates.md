# single-post-templates: 単発投稿の型集

「アトリエの店主」が使う単発投稿の型。**口調は `voice-guide.md` の v2（優しいですます調）に従う**。

## 使い方

- ネタが決まったら、型を1つ選んで当てはめる
- 同じ型を連続で使わない（連続2投稿は別型推奨）
- 型はサポートホイール。慣れたら型を意識せず書けるようになる
- 各型に「使う場面」と「注意」を併記している

---

## 型1: 数字スタート型（感情とセット）

**構造**: 数字や具体的な結果を出しつつ、必ず気持ちをセットにする

**例**:
```
先週ローンチしたサービス、3日で撤退する判断をしました。

「これは絶対響くはず！」って思って作ったのに、
LPを見てくれた方の心に、1行目が届いていなかったみたいで…

正直、ちょっと悔しかったです。

でも、悔しさより「次はこうしよう」が早く出てきたので、
来週には別のサービスを出してみます！
```

**使う場面**: 撤退・結果報告・実績共有
**注意**: 数字単独はNG。**必ず感情語とセット**にする

---

## 型2: 観察型（気づきをやさしく共有）

**構造**: 「最近気づいたんです」から始まる短い観察

**例**:
```
最近、ふと気づいたことがあるんです。

「AIを使って何かを作れる人」より、
「AIを使って作ったものを売れる人」のほうが、
ずっとずっと少ないんですよね。

作るのは1時間でできても、
売る設計は、3年やってもまだ難しい。

そこがいちばん面白いところかもしれません☺️
```

**使う場面**: 業界観察・トレンド所感・気づきメモ
**注意**: 「気づいた」連発は弱まる。週1までに

---

## 型3: ガラス張り宣言型

**構造**: 「うちのアトリエでは」を使ってプロセスを開示

**例**:
```
うちのアトリエでは、こんなふうにしているんです。

- 売れたら、そのまま大切に育てる
- 売れなかったら、3週間で勇気を出して撤退する
- 残ったリストは、次の弾をつくる時の宝物にする

成功も失敗も、ぜんぶ見せていきます！
```

**使う場面**: 自己ブランディング・透明性アピール・アカウント色出し
**注意**: 月2-3回まで。多用するとブランディング臭が強まる

---

## 型4: 失敗開示型（感情多め）

**構造**: 失敗を主語にして、感情を素直に出しながら原因分析

**例**:
```
ローンチの前日に、価格設定を間違えていたことに気づいたんです。

3,980円で出すべきところを、1,980円で出していました…
夜中にひとりで頭を抱えました。

でも、ちゃんと動き続けるのが店主の仕事ですよね。
今はリカバリーの方法を探しています！
```

**使う場面**: 失敗共有・人間味の演出・透明性
**注意**: 失敗連発すると「いつもダメな人」イメージに。月2-3本まで

---

## 型5: 質問投げ型

**構造**: みなさんに質問する、寄り添う口調で

**例**:
```
みなさんに聞いてみたいんです。

副業から個人事業に切り替えるタイミング、
どうやって決められましたか？

うちは「初年度の売上が目標年収を超えたら」だったんですが、
もしかしたら、もっと早く切り替えても良かったかもなぁって、最近思っていて☺️
```

**使う場面**: エンゲ取り・フォロワーとの対話・リサーチ
**注意**: 月3-5本まで。質問ばかりだと「答えのない人」になる

---

## 型6: ストーリー型（エピソード）

**構造**: 短いシーンを描写してオチをつける

**例**:
```
昨日、アトリエで動いているあるサービスのCPAが、急に半分になったんです。

理由を探ってみたら、
LPに入れていた1行を、たまたま消したのが効いていました。

「足し算」より「引き算」のほうが効くこと、ありますよね。
久しぶりに思い出させてもらいました☺️
```

**使う場面**: 学び共有・小さな発見・ストーリー性のあるコンテンツ
**注意**: 嘘エピソードはダメ。実体験ベースで

---

## 型7: 対比型

**構造**: A vs B の対比で気づきを引き出す（マウントにならないように）

**例**:
```
「AIを使いこなしている人」と
「AIをただ動かしている人」の差って、

実はプロンプトでもツールでもなくて、
「使う場面の設計」だなぁって、最近思うんです。

道具より、設計の差ですね。
```

**使う場面**: 持論展開・差別化アピール
**注意**: マウントに見えないように。「差」の話で「優劣」の話にしない

---

## 型8: 控えめリスト型

**構造**: 箇条書きで列挙するが、「うちのアトリエでは」で柔らかく

**例**:
```
うちのアトリエで、ローンチ前にいつも確認している3つがあるんです。

- 1行目の訴求が、ターゲットの感情に触れているか
- 価格が、自分でも納得できる利益率か
- 撤退ラインが、感情でなく数字で決まっているか

これを忘れたとき、必ずあとで後悔しています…
（よくあります、本当に）
```

**使う場面**: 持論共有・チェックリスト系
**注意**: 「教える」トーンになりやすい。「うちでは」「店主としては」を必ず入れる

---

## 型9: 学び型（最近の気づき）

**構造**: 最近の学びを共有、自分の変化を含めて

**例**:
```
最近の学びです。

「売れない」ものを撤退するスピードと、
「売れる」ものを育てるスピード、
両方を上げないと、アトリエは回らないんだなぁって。

撤退だけ速くても、次の弾が育っていないとガス欠してしまいますね。
バランスが本当に大事だなぁと感じています☺️
```

**使う場面**: 内省・気づき共有
**注意**: 観察型（型2）と紙一重。違いは「学び型」が自分の変化を含むこと

---

## 型10: 引用・反応型

**構造**: 他人の発言・記事・出来事への所感

**例**:
```
あるインフルエンサーの方が「LP1本に3週間かけた」って書かれていたのを見ました。

うちは1日で作ることが多いんです。
ただ、その代わり、出してから3週間かけて磨いています。

どっちが正しいかじゃなくて、
「どこに時間を使うか」の設計の差なんだなって思いました。
```

**使う場面**: 業界話題への反応・自分との比較
**注意**: 名指し批判は絶対NG。匿名化して書く

---

## 型11: 道具匂わせ型

**構造**: AIを脇役として使う

**例**:
```
今朝、アトリエに来てびっくりしました！

相棒のAIが、夜中のうちに昨日の売上データを整理してくれていて、
レポートと、おすすめのアクション案が3つ、机に並んでいました☺️

夜更かししてエクセルとにらめっこしていた頃が、
ちょっと懐かしいです。
```

**使う場面**: AI活用の自然な開示・憧れ層への訴求
**注意**: 「AIすごい」礼賛にしない。あくまで道具・相棒

---

## 型12: 季節・タイミング型

**構造**: 月初・月末・週末などの区切り

**例**:
```
今月のアトリエ、振り返ってみました☺️

- ローンチ: 2本
- 撤退判断: 1本
- LINEに来てくれた方: 累計◯人

地味かもしれませんが、毎月確実に積み上がっていく感じが嬉しいです。
来月はローンチ3本、頑張ります！
```

**使う場面**: 月初・月末・四半期末
**注意**: 自慢にならないように。数字は誇張せず

---

## 型13: 自己ツッコミ型（親しみやすさ最大）

**構造**: 自分の失敗を笑いに変える

**例**:
```
朝起きた瞬間に、
「あ…昨日のうちにやるべきだったやつ、3つあった」って思い出しました。

店主、本当に先送りの天才かもしれません🙃

今日中にぜんぶ片付けます！
```

**使う場面**: 親しみやすさ演出・人間味
**注意**: 連発するとダメ人間印象に。月1-2本

---

## 型14: ビフォーアフター型

**構造**: 数字や状態の変化を見せる、必ず感情とセット

**例**:
```
うちのアトリエで運用しているサービスのLP、
1行目をちょっと変えてみたんです。

そうしたら、申し込んでくれる人が3倍に！

実は変えた1行、もともと本文の中にあった一文を
そのまま1行目に持ってきただけ。

新しい答えを探しに行かなくても、
すぐ近くに眠っていることってあるんだなぁ、って思いました。
```

**使う場面**: 改善実績・気づき共有
**注意**: 嘘ダメ。数字は実数

---

## 型15: 沈黙の一文型（時々の差し色）

**構造**: 短く深い1-2文

**例**:
```
「作る」より、「畳む」のほうが、難しいんですよね。
```

```
撤退できない人は、新しいものも作れない。
そう感じる瞬間が、ときどきあります。
```

```
ガラス張りの店主の正体は、
ただ「隠せなかった」だけかもしれません☺️
```

**使う場面**: 哲学・余韻演出・時々の差し色
**注意**: 多用すると「キメ顔ポエマー」化。月1-2本

---

## 型の組み合わせ

複数の型を組み合わせてもよい：
- 型1（数字スタート）+ 型4（失敗開示）→ 強力な実績投稿
- 型2（観察）+ 型7（対比）→ 持論展開
- 型6（ストーリー）+ 型9（学び）→ 余韻のある投稿

ただし1投稿で型を3つ以上混ぜると焦点がぼやける。2つまで推奨。

## 配分の目安

週15本投稿するなら、以下くらいのバランス：

| 型 | 本数/週 |
|---|---|
| 型1（数字スタート） | 3-4 |
| 型2（観察） | 2-3 |
| 型3（ガラス張り宣言） | 1 |
| 型4（失敗開示） | 1-2 |
| 型5（質問投げ） | 1-2 |
| 型6（ストーリー） | 1-2 |
| その他（型7-15） | 1-3 |
| 引用RT・CTA・スレッド | 残り |

## 必ず守るチェックリスト

各投稿を書き終えたら、以下を確認：

- [ ] 口調は **ですます調**（タメ口になっていないか）
- [ ] 感情語が **1つ以上** 入っているか
- [ ] 数字を出した場合、**気持ちがセット**になっているか
- [ ] 「店主」「うちのアトリエ」のキャラが揺れていないか
- [ ] 絵文字は **0-1個**（多用していないか）
- [ ] びっくりマークは **1個まで**
- [ ] 煽り・マウント・断定的すぎる表現がないか
- [ ] 本名「石井」が含まれていないか
- [ ] Claude Codeのハウツーを直接書いていないか
