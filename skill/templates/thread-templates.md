# thread-templates: スレッドの型集

スレッド（連投）の型を集めた。週1-2本ペース。
**口調は `voice-guide.md` v2（優しいですます調）に従う**。

## スレッドの基本原則

- 5-10ポスト。10超は離脱率が上がる
- 1ポスト目（フック）が一番大事。これだけ独立で読まれる
- 結論は早めに出す。引っ張りすぎない
- 最後のポストにCTA入れてOK（ただし月1-2本程度）
- 各ポストは280文字以内（Xの仕様）
- **感情語を必ず散りばめる**

## 型T1: プロジェクト全記録型

**構造**: あるプロジェクトの始まりから今までの記録

**ポスト1**（フック）:
```
うちのアトリエで先週ローンチして、3日で撤退する判断をしたサービスがあるんです。

今日はその全記録を書いていきますね。
失敗の中身、ぜんぶ出します。
```

**ポスト2**（背景）:
```
作ったのは、ある業界向けのマッチング系サービスでした。

「△△で困っている◯◯な人が、いまの選択肢に満足していないはず」という仮説を立てて、
半月で形にして、広告に20万投じてみました。
```

**ポスト3**（結果）:
```
結果はこんな感じでした…

・申し込んでくれた人数は、目標の半分
・有料につながった人はゼロ
・かけたお金は20万

これは…と思って、3日でストップ。撤退の判断を出しました。
```

**ポスト4**（学び）:
```
なんでこうなったのか、振り返ってみると3つあって。

1. ターゲットの困りごとを読み違えていたこと
2. LPの1行目が、感情に触れる文になっていなかったこと
3. オファーの価格設定が、ハードルを高くしすぎていたこと

特に効いていたのは、1行目だなぁと思っています。
```

**ポスト5**（次に活かす）:
```
このサービスから学んだこと、ちゃんとメモに残しました☺️

・仮説は3回検証してからLPを作る
・1行目は5パターン用意してテスト
・価格は3段階用意

撤退の判断が早かった分、次の弾はもう設計しています。
来週には別のサービスを出してみますね！
```

**ポスト6**（CTAあり版・任意）:
```
こういう「全記録」を、もう少し深く書いているのが
LINE「アトリエ店主の部屋」です☺️

ここに書ききれない数字や、毎月の試行錯誤を流しています。
よかったら覗いてみてください🙏
https://lin.ee/xxxxx
```

**使う場面**: 月1のメインコンテンツ・撤退や成功の記録
**注意**: CTAは月1-2回まで。なくてもOK

## 型T2: 数字深掘り型（感情とセットで）

**構造**: ある事業の数字を細かく分解、必ず気持ちを添える

**ポスト1**（フック）:
```
うちのアトリエで運用している、あるサービスの先月の数字、
公開していい範囲でぜんぶ書いてみますね。
```

**ポスト2**（売上内訳）:
```
売上の内訳はこんな感じでした。

- 商品A: 全体の半分くらい
- 商品B: 3割くらい
- 商品C: 2割くらい

商品Aが思ったより伸びてくれて、ほっとしました☺️
```

**ポスト3**（コスト）:
```
コストのほうも見ていきますね。

- 広告費: 売上の◯%
- 外注費: 売上の◯%
- SaaSの月額: 売上の◯%

正直、広告費が想定より食い込んでいて、ちょっと焦りました。
```

**ポスト4**（利益）:
```
利益率は、結果として◯%でした。

もう少し取れると思っていたんですが、広告費の食い込みが大きかったですね…
でも赤字じゃなかっただけ、ほっとしています。
```

**ポスト5**（次の方針）:
```
来月の方針、ちゃんと決めました。

- 広告費を少し抑える
- リスト経由の販売を増やす
- 利益率の高い商品Cをもう少し伸ばす

数字を見ながら、丁寧に整えていきます！
```

**使う場面**: 月初・月末・四半期末
**注意**: 守秘義務のある数字は出さない。公開できる範囲で

## 型T3: 思考の解剖型（迷いを優しく語る）

**構造**: 「なぜそう判断したか」を細かく開示、迷いも見せる

**ポスト1**（フック）:
```
昨日、あるサービスを「育てる」じゃなく「畳む」判断をしました。

その判断、どうやって出したのか、書いてみますね。
（けっこう迷ったんです…）
```

**ポスト2**（前提）:
```
そのサービス、3ヶ月運用していて、
月の売上もちゃんとありました。

数字だけ見たら、育てたほうが良さそうに見えたんです。
```

**ポスト3**（迷った点）:
```
迷ったのは、こんなところでした。

「このまま育てたら、半年後にどこまで行くか」
「他にやりたいことに時間を取られるか」
「精神的な負荷はどうか」

3つとも、なかなか答えが出なくて。
```

**ポスト4**（決め手）:
```
最終的に「畳む」にした決め手は、

「3ヶ月で◯倍に伸びなかった事実」と、
「育てるための新しい仕掛けが、自分の中に浮かんでいない事実」でした。

伸びる気配があるなら、続ける。
ないなら、潔く畳む。
```

**ポスト5**（学び）:
```
今回学んだこと、メモに残しました☺️

- 月の売上だけで判断しない
- 「次の半年の伸びしろ」を見る
- 「自分のリソースをそこに使うか」を問う
- 答えが出ないなら、畳むほうが早い

撤退って、いつまでも難しいですね…
```

**使う場面**: 大きな意思決定をシェアするとき
**注意**: 結論ありきで書かない。本当に迷った事実を書く

## 型T4: 失敗事例集型

**構造**: 複数の失敗をまとめて公開、優しく振り返る

**ポスト1**（フック）:
```
うちのアトリエで、過去1年でローンチしたサービスは12個ありました。

そのうち、9個は撤退したんです…
打率にしたら2割5分くらいですね。

ぜんぶ、何で撤退したか書いていきます。
```

**ポスト2-6**（各サービス）:
```
1個目: マッチング系サービス
撤退理由: ターゲットが狭すぎて、広告が刺さりませんでした。

2個目: コンテンツ販売
撤退理由: 既存の競合が強すぎて、差別化できる切り口を作れず…

3個目: ...
```

（複数のサービスを淡々と並べる）

**ポスト最終**（まとめ）:
```
12個ローンチして、9個撤退。
打率としては、正直そんなに高くないですよね。

でも、撤退する勇気がなかったら、
今ある3つの「育っているサービス」は生まれなかったと思うんです。

打席に立つ数を増やすこと。
撤退の速度を上げること。

地味だけど、これがアトリエ流かもしれません☺️
```

**使う場面**: 半年・1年の振り返り
**注意**: 守秘義務のあるサービス名は伏せる

## 型T5: ロードマップ型

**構造**: これまでとこれからを並べて見せる

**ポスト1**（フック）:
```
Atelier Base を始めて、今で◯ヶ月目になりました。

これまでに何をやったか、これから何をやるか、
ぜんぶ書いてみますね。
```

**ポスト2**（これまで・前半）:
```
最初の3ヶ月:

- ◯◯と◯◯をローンチ → どちらも撤退
- 学んだのは「需要の読み違い」が一番怖いということ

正直、しんどかった時期です…
```

**ポスト3**（これまで・後半）:
```
4-6ヶ月目:

- ◯◯をローンチ → これは育てる判断
- リスト集約の仕組みを作り始める
- 売上はじわじわと◯倍に

少しずつ、形が見えてきました。
```

**ポスト4**（現在地）:
```
いまのアトリエ:

- メインサービス3つ
- LINEに来てくれた方は累計◯人
- 月次売上◯◯
- リスト集約のCPA◯◯

ようやく「アトリエらしさ」が出てきた感じです☺️
```

**ポスト5**（これから・短期）:
```
これからの3ヶ月でやりたいこと:

- 新規サービスを2つローンチ
- LINEのステップ配信を整える
- うちの仲間と一緒に仕掛けを作る
```

**ポスト6**（これから・長期）:
```
1年後の目標も、書いておきますね。

- リスト◯◯人規模に
- コンサル事業の本格化
- Atelier Baseの法人化

ぜんぶ、ガラス張りで進めていきます！
```

**使う場面**: 節目・四半期末・年末
**注意**: 大風呂敷を広げすぎない。届かなかった時にダサい

## 型T7: 比較・選別型

**構造**: 複数の選択肢を比較して結論を出す

**ポスト1**（フック）:
```
「副業で月100万を目指す」場合、
うちのアトリエが見てきた範囲で、現実的な選択肢は3つあると思っています。

向き不向きと、撤退の目安も書いていきますね。
```

**ポスト2-4**（各選択肢）:
```
選択肢1: コンテンツ販売

向いている方: 自分の経験・知見がある方
あまり向かない方: 経験を言語化するのが苦手な方
撤退の目安: 3ヶ月で売上ゼロが続くなら、見直したほうがいいかも
```

```
選択肢2: 物販・EC
...
```

```
選択肢3: コミュニティ・コンサル
...
```

**ポスト最終**（まとめ）:
```
正解はないんですよね、本当に。

自分の「向き」と「リソース」と「リスク耐性」で決めていく感じです。

うちのアトリエでは、3つぜんぶやっています。
理由は「分散」。1つに集中するより、複数で打席に立つほうが、
全体として勝率が上がるからです☺️
```

**使う場面**: 持論展開・読者の判断材料提供
**注意**: 「これが正解」とは言わない。選択肢の提示にとどめる

## スレッドの注意点

1. **1ポスト目（フック）に最も時間をかける**
   - ここで読み手が判断する
   - 「今日は◯◯について書いていきますね」が効く
   - 感情語（「ちょっと迷ったんです」「びっくりしました」）を1つ入れると引きが強い

2. **2ポスト目で結論や全体像を出す**
   - 引っ張ると離脱する
   - 「結論から言うと〇〇」のパターンが安定

3. **各ポストは独立して意味が通るように**
   - 「続き」だけのポストは弱い
   - 各ポストにミニ完結性を持たせる

4. **改行を多めに**
   - 1ポスト内も、3-4行ごとに改行
   - スマホで読まれることを意識

5. **CTAは最後だけ**
   - 中間ポストに「LINE登録は▼」を入れない
   - 流れを切らない

6. **保存・引用RTされやすい構造**
   - 数字、リスト、まとめ
   - 「あとで見返したい」と思わせる

7. **絵文字は控えめに、優しい温度を上げる用途で**
   - スレッドでも合計1-2個
   - フックと最後のポストに入れるのが効く

## 配分の目安

週に1-2本のスレッド。月で言うと4-8本。

| 型 | 月の本数 |
|---|---|
| 型T1（プロジェクト全記録） | 1 |
| 型T2（数字深掘り） | 1 |
| 型T3（思考の解剖） | 1-2 |
| 型T4-T7 | 適宜 |

## チェックリスト（スレッド全体）

- [ ] フック（ポスト1）に感情語や引きがあるか
- [ ] 結論が早めに出ているか
- [ ] 各ポストが独立して読めるか
- [ ] 口調は **ですます調**
- [ ] 感情語が散りばめられているか
- [ ] 数字には気持ちがセットになっているか
- [ ] 全体で絵文字は1-2個まで
- [ ] CTAは最後だけ（中間NG）
