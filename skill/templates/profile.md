## プロフィール各要素の構成意図

### 表示名
**「ひろ｜AI実業家」**

- 「ひろ」: 親しみやすさ・呼びかけやすさ（本名「ひろともの」の前半、緩やかな匿名）
- 「｜AI実業家」: 「何の人か」を一発で明示（X 2026 アルゴリズムが「ベクトル一貫性」を求めるため、肩書きは明示）

### 自己紹介本文（160文字制限内）

#### 1行目：何の人か（コア）
```
Claude Code と Codex を相棒に、Webサービスを量産する個人事業家。
```
- **Claude Code / Codex** を明示 → ニッチ専門性
- 「相棒」表現でAIへの愛着・親しみを出す
- 「量産する個人事業家」で実業家ポジション強調

#### 2行目：何を提供するか（ベネフィット）
```
海外で先行しているAI開発のトピックを、日本語で噛み砕いて発信中。
```
- フォローするメリット明示（海外最新を日本語で）
- 「噛み砕いて」で初心者〜中級者にも届く印象

#### 3行目：頻度の予告
```
「AIで事業を作る」リアルを、毎日3投稿。
```
- 1日3投稿の宣言 = 信頼性
- 「AIで事業を作る」でテーマを再強調

#### 4行目：屋号
```
Atelier Base 代表
```
- 屋号を静かに添える（実在感担保、企業HPと整合）
- ※ 「ミライ塾」の名前は出さない（X上では非表示）
