# cta-post: LINE誘導CTA投稿テンプレート

月1-2回流す、LINE「アトリエ店主の部屋」への誘導投稿。

## 鉄則

- **頻度: 月1-2回まで**。毎日CTAだと「売り込みアカウント」と認定される
- **必ず「裏側」「限定」「制作秘話」など**、Xで読めないものを匂わせる
- **押し売りしない**。店主キャラの自然な振る舞いとして書く

## 採用候補 v1（標準）

```
店主の部屋では、Xには書ききれない
「あの撤退判断、本当は◯◯だった」
「次に仕掛けてる、まだ言えないプロダクト」
みたいな裏話を不定期に流してます。

▼ 入口はここ
https://lin.ee/xxxxx
```

## バリエーション

### A. ベネフィット列挙型

```
LINE「アトリエ店主の部屋」では、こんなのを流してます。

- うちのアトリエの制作秘話
- 撤退の本当の理由
- まだ言えない次のプロダクト
- 店主のサービス展開術

合いそうな人だけどうぞ。
https://lin.ee/xxxxx
```

### B. 申し訳なさ型（謙虚なトーン）

```
Xに書きたいけど、書ききれない話がいくつかあって、
「店主の部屋」というLINEで流してます。

撤退の本当の理由とか、いま仕掛けてるやつの設計図とか。
合う人だけ来てもらえれば。

https://lin.ee/xxxxx
```

### C. アンケート訴求型（セグメント分けを前面に）

```
店主の部屋（LINE）、初日にアンケートを取ってます。

- いまの状況
- 直近進めたいこと
- 売上レンジ

その3つで、その人に合いそうなサービスや情報を
ご案内するための仕組み。

合う人だけ。
https://lin.ee/xxxxx
```

### D. ストーリー型（具体的なエピソード）

```
先週、ある撤退判断をした。

理由はXに書いたけど、もう一段奥の話
（仕入れの数字、本当に踏ん張れなかった点）は
店主の部屋（LINE）で書いた。

そういう「もう一段奥」を時々書いてる場所。
https://lin.ee/xxxxx
```

### E. 直球型（短尺・伸びた投稿の流れで）

```
ここの裏側は「店主の部屋」で。
https://lin.ee/xxxxx
```

→ 伸びた投稿のリプ欄や引用RTで、軽く添える用。

## 投稿タイミング

### ◎ 流すといいタイミング

1. **伸びた投稿の翌日**: 注目が集まっている時に流す
2. **新規プロダクトを匂わせた直後**: 「詳しくはLINEで」の流れ
3. **撤退判断を共有した直後**: 「もう一段奥の話はLINEで」の流れ
4. **月初・月末**: 区切りのタイミング

### ✗ 避けるタイミング

1. **連続2日でCTA**: NG
2. **同じ週に2回**: NG（よほどの事情がなければ）
3. **投稿初期（フォロワー100以下）**: CTAより、まず世界観を浸透させる

## 効果測定

- LINEリンクのクリック数（短縮URLのアナリティクスで取得）
- 投稿後72時間のLINE登録増加数
- アンケート回答内訳（セグメント分布）

これらは `references/06-analyze.md`（次ターン作成）で扱う。

## 注意

- LINEリンクは bit.ly / lin.ee / oremo.ne など、変更可能なものを使う
- 同じURLを使い続けるとアルゴリズム的に評価が下がる可能性があるので、定期的に差し替え
- CTA投稿そのもののエンゲージメントは低くなる傾向。**伸びは気にせず、CVRだけ見る**
