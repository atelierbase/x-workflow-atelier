- 文面:

Claude Code の運用で迷う「CLAUDE.md vs Hooks」問題。

ざっくり整理すると：
・CLAUDE.md = 助言レベル（約80%遵守）
・Hooks = 強制執行（100%遵守）

「あったらいいな」レベルは CLAUDE.md、
「絶対やって」レベルは Hooks。

例：format/lint は Hooks、
コーディングスタイルガイドは CLAUDE.md。

私はこの基準で運用しています。
